## revenge-game: DeepBagClip `spread` assumes negative values (2026-10-08)
In `DeepBagClip.tsx` the spread axis is `dLo = floor(min(values, -1) - 0.5)` to `0`, so positive values (e.g. +0.18 to +0.72 across specs) render off the right edge, and when the minimum sits just above an integer (e.g. -11.07 -> dLo -12) the leftmost dot's value label lands on the row labels (both shapes; in 4:5 it also runs off the left edge). Also, a two-line `spread.label` in 4:5 collides with the brand line at the top. Request: domain `[min(0, lo) - pad, max(0, hi) + pad]` with ticks from a nice-step function, value labels placed on the side away from the label column, and the label block offset below the brand line.
Workaround used: clip.json has `spread: null`; a study-scoped wrapper `ebk-studio/studies/revenge-game/RevengeClip.tsx` renders DeepBagClip unchanged and draws a positive-axis version of the beat in the same window, rendered by `studies/revenge-game/render.mjs` (own entry + `.bundle-deepbag-revenge`, outside `src/`).
   (champagne-no-hangover workaround for item 4: structurally empty cells are omitted from `cells`, so they draw nothing; the Flat view then shows "n/a" for them.)
- **DONE.** Nice-step domain with padding, value labels on the side away from the row labels (and lifted above the line when they must cross it), content kept below the brand line in both shapes. The wrapper's fan beat is folded into the shared composition as `spread.style: "fan"`; the old `fan` block in clip.json is read as-is, so clip.json is unchanged. `ebk-studio/studies/revenge-game/` and `.bundle-deepbag-revenge` are deleted; this study renders with `render_deepbag.mjs` and the `stadium` motif.
