# EBK data notes (read before touching data)

Standing rules (owner): every sport runs through its latest COMPLETE season (check against today's date); only real sources; never invent player-seasons or position overrides. Pinning a figure to the official record is allowed only in an `OFFICIAL_FIXES` table (data/build_players.py, build_cfb.py, build_soccer.py) with the source URL beside it.

## Windows (first season in the data)
NFL 1999 (nflverse; nothing earlier is free), CFB 2014 (plus lazy pre-window and 2014-15 rows from ESPN), NBA 2002 (ESPN box scores; nothing earlier reachable), MLB 1990 (Lahman through 2021 + MLB Stats API), NHL 1979-80 (NHL stats API), Premier League 2016-17 (FPL; labelled "FPL Assists"). Veterans' pre-window seasons come from lazy side files (see Source quirks), so grid career categories read "(career)" for NFL, NBA, MLB and NHL; soccer keeps "(since 1992-93)" for goals and "(since 2016)" for FPL assists/points/clean sheets.

## Build order
1. `python data/build_<sport>.py` (NFL: build_players.py, which also applies `raw/espn_def_overlay.json` made by `python data/build_espn_overlay.py`; ESPN caches in raw/espn_def and raw/espn_off come from tools/espn_def_fetch.cjs and espn_off_fetch.cjs).
2. NHL/MLB only: `python data/nhl_headshots.py` / `python data/mlb_headshots.py` (verified photos for old players), then `python tools/slim_v4.py` (browser copy `players.slim.json`).
3. `node tools/build_grid_roster.cjs`, `python tools/build_stat_lab.py`, `node tools/solvable.cjs` (must be 0 errors; run several --date values).
4. Bump the data version: `EBKD.dataUrl` in public/js/ebk-loader.js, ROSTER_URL in player-grid.js, DATA_V in ebk-home-sections.js.
5. Tests: tools/smoke.cjs needs full playwright; on this PC run a copy with `require("playwright-core")` and `chromium.launch({channel:"msedge"})`; list a throwaway sport first (the first sport can hit a server-start race). tools/deep-cut-smoke.cjs works as is.

## Source quirks
- NFL games: nflverse counts only games with a recorded stat; ESPN gamesPlayed is applied as max(nflverse, ESPN) up to 17/18 weeks (a trade across a bye can exceed the schedule). Tackles: ESPN only for 1999-2003 where it differs >10%; sacks/INT ESPN through 2012. Evidence in docs/data-audit-20261010.md and docs/audit-evidence/.
- Full careers: `data/raw/career/<sport>.json` (raw, not shipped; records in the main shape for seasons before the window, ONLY players already in the main file, no headshots) -> `python tools/slim_v4.py --career` -> `public/data/[<sport>/]career.json`, fetched lazily by Career Path (and the grid's no-roster fallback) via `EBKD.loadCareer` + `EBKD.mergeCareer` (rows flagged `pre:true`, appended after the main rows). Higher/Lower, Stat Line and Team Study never load it. `tools/solvable.cjs` and `build_grid_roster.cjs` merge the raw file, so grid-roster.json already contains full careers. Builders: MLB `python data/build_mlb.py --career` (Lahman, 1871+), NHL `python data/build_nhl.py --career` (NHL API 1917-18+), NFL `data/build_nfl_career.py` (ESPN cache -> raw/career/nfl_espn.json) then `data/reconcile_nfl_career.py` (Statscrew team rosters 1983-1998 from tools/statscrew_nfl_fetch.py: adds seasons ESPN omitted, corrects games/clubs, club order from `data/nfl_gamelog_order.py`; writes raw/career/nfl.json + nfl_sources.json with provenance and games started), NBA `data/build_nba_career.py` (ESPN, 1985-2001), soccer `data/build_soccer_career.py` (premierleague.com stats API via curl, 1992-93 to 2015-16, goals and minutes only). CFB `data/build_cfb_career.py` (ESPN college stats cache from tools/espn_cfb_fetch.cjs plus CFBD FBS team lists from tools/cfbd_pre_fetch.py; adds seasons <= 2015 the main file lacks, incl. 2014-15 defenders). Rebuild them after any change to a main file's player ids. CFB games stay 0 (no source); CFBD has no defense before 2016.
- Known gaps: NFL pre-1999 has no tackles (unofficial), 26 rows exist only in ESPN, a few traded seasons have an unknown club order; soccer pre-2016 has goals only and clubs ordered by appearances; WHA seasons are not in the NHL data.
- Higher/Lower pools: EBKD.hlEligible(p, key, label, sport) has games floors for NHL (skaters 20, goalies 15) and MLB (hitters 50, pitchers 20).
- Team codes are folded into today's franchise in public/js/<sport>-teams.js (NHL: PHX/WIN->ARI, ATL->WPG, AFM->CGY, HFD->CAR, QUE->COL, MNS->DAL, CLR->NJD; MLB keyed by Lahman franchID: Expos->WSN, Marlins FLA, Devil Rays TBD, Angels ANA).
- Deep Cut: edit data/deep-cuts/bank_*.json, then PATCH the affected days in public/data/deep-cuts.json with build_deep_cuts.pack(); a full rebuild reshuffles future days.
